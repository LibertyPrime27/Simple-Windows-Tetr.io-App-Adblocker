# Tetr.io Windows App Ad Blocker

This is a little executable that I made with the help of AI that blocks ads from rendering in the Tetr.io Windows app. To use it, simply make sure you have the actual Tetr.io app downloaded, then download the exe and store it wherever you want. To use it, open the Tetr.io app with ads; you have to use the executable each time you want the app to have no ads.

THE EXE MIGHT FLAG WINDOWS DEFENDER IF YOU DONT TRUST IT YOU CAN SEE THE SOUCE CODE IN THE BAT VERSION OF IT IN THE REPOSITROY FILES AND JUST USE THAT IF YOUD LIKE.

ONLY WORKS IF TETR.IO IS INSTALLED IN THE DEFAULT PATH!!!
